# Atlas des territoires de NovyLand

Éditeur de cartes autonome, intégré au Labo : `/labo/atlas/`.

- Grille 15 × 15, territoires et lieux superposés.
- Noms et notes par case, gomme et annulation.
- Sauvegarde locale dans le navigateur, import/export JSON et impression.

Les fichiers sont statiques : aucune installation ni compilation nécessaire.
La publication suit celle du site GitHub Pages.

Pour transférer une carte depuis l’ancienne application Sites, utilisez **Exporter** sur l’ancienne adresse, puis **Importer** ici. Les sauvegardes ne sont pas synchronisées entre adresses ou appareils.
